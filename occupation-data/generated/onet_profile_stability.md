# Độ nhạy của gợi ý nghề IT với trọng số

Sinh bởi `occupation-data/scripts/check_profile_stability.py`. Mỗi kịch bản đổi trọng số một nhóm, rồi so top 3 với trọng số gốc.

| Kịch bản | Nghề đổi top 1 | Nghề đổi tập top 3 |
|---|---|---|
| Trọng số gốc | 0 / 22 | 0 / 22 |
| Sở thích RIASEC (6) × 0.5 | 2 / 22 | 7 / 22 |
| Sở thích RIASEC (6) × 2 | 3 / 22 | 7 / 22 |
| Work Styles (21) × 0.5 | 6 / 22 | 6 / 22 |
| Work Styles (21) × 2 | 3 / 22 | 11 / 22 |
| Essential + Transferable Skills (35) × 0.5 | 1 / 22 | 2 / 22 |
| Essential + Transferable Skills (35) × 2 | 4 / 22 | 3 / 22 |
| Mọi nhóm bằng nhau | 7 / 22 | 6 / 22 |

## Nghề đổi top 3 ở ít nhất một kịch bản

- Lập trình viên Front-end: Lập trình viên Game, Lập trình viên Mobile, Lập trình viên Back-end (gốc)
- Lập trình viên Back-end: Kỹ sư phần mềm nhúng / IoT, Chuyên viên phân tích nghiệp vụ, Kỹ sư DevOps (gốc)
- Lập trình viên Mobile: Kỹ sư phần mềm nhúng / IoT, Chuyên viên phân tích nghiệp vụ, Kỹ sư DevOps (gốc)
- Lập trình viên Game: Chuyên viên thiết kế UI/UX, Lập trình viên Front-end, Lập trình viên Mobile (gốc)
- Chuyên viên thiết kế UI/UX: Lập trình viên Game, Lập trình viên Front-end, Lập trình viên Mobile (gốc)
- Kỹ sư phần mềm nhúng / IoT: Lập trình viên Mobile, Lập trình viên Back-end, Kỹ sư DevOps (gốc)
- Trưởng nhóm kỹ thuật: Kiến trúc sư giải pháp, Chuyên viên tư vấn giải pháp ERP, Kỹ sư DevOps (gốc)
- Kiểm thử: Kỹ sư dữ liệu, Kỹ sư phần mềm nhúng / IoT, Kỹ sư DevOps (gốc)
- Chuyên viên phân tích dữ liệu: Kỹ sư dữ liệu, Kỹ sư trí tuệ nhân tạo, Chuyên viên tư vấn giải pháp ERP (gốc)
- Kỹ sư trí tuệ nhân tạo: Lập trình viên Mobile, Lập trình viên Back-end, Lập trình viên Front-end (gốc)
- Kỹ sư dữ liệu: Kỹ sư DevOps, Kỹ sư hệ thống mạng, Lập trình viên Mobile (gốc)
- Chuyên viên kiểm thử xâm nhập: Kỹ sư an ninh mạng, Kỹ sư DevOps, Kỹ sư hệ thống mạng (gốc)
- Chuyên viên phân tích nghiệp vụ: Chuyên viên tư vấn giải pháp ERP, Lập trình viên Mobile, Lập trình viên Back-end (gốc)
- Quản lý sản phẩm: Trưởng phòng Kỹ thuật, Trưởng nhóm kỹ thuật, Chuyên viên tư vấn giải pháp ERP (gốc)
- Nhân viên hỗ trợ kỹ thuật / IT Support: Chuyên viên phân tích nghiệp vụ, Kỹ sư điện toán đám mây, Chuyên viên tư vấn giải pháp ERP (gốc)
- Kỹ sư hệ thống mạng: Kỹ sư điện toán đám mây, Kỹ sư DevOps, Kiến trúc sư giải pháp (gốc)
