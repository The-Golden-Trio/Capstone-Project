Junior Fullstack Engineer (AI-First)
About the job
Nexlab Technology

NexlabTechnology is a software company based in Ho Chi Minh City. We build products and solutions for enterprise clients across healthcare, education, manufacturing, tourism, and commerce.

Our development process follows an AI-First, Spec-Driven Development model: specifications are the single source of truth, AI coding agents handle most of the building work, and engineers are responsible for directing the process, verifying output, and making quality decisions.

About The Role

As a Junior Fullstack Engineer, you own an entire small-to-mid-scale web product, from frontend down to backend and database, on projects where teams are not split by layer.

You participate in the full development lifecycle: Specification, Design, AI-assisted Development, Testing, Deployment, and Monitoring. Rather than just picking up tasks and writing code, you are responsible for understanding the problem, providing precise instructions to an AI coding agent, verifying its output, and making sure the system works correctly in a real environment.

Key Responsibilities

Full-stack development with AI coding agents: read specifications and business requirements, translate them into prompts with proper context and constraints for the AI, and break large features into smaller tasks the AI can implement effectively. Maintain project context: architecture, conventions, design system, and database rules.

Frontend: build web applications and business interfaces using HTML, CSS, JavaScript/TypeScript, and React. Create reusable components, integrate APIs, handle responsive layouts and loading/empty/error states. Track Core Web Vitals and bundle size.

Backend, data, and integration: design RESTful APIs,build business logic, design database schemas and migrations. Write SQL with JOINs, handle indexes and transactions. Implement authentication and authorization. Integrate third-party systems, handle retry logic, idempotency, and error handling. Debug issues end-to-end from frontend through to the database.

Testing: write automated tests for business-critical flows. Verify AI output and catch errors the AI commonly misses: incorrect business logic, security vulnerabilities, race conditions, N+1 queries, and incomplete error handling.

Deployment: participate in pushing products to staging and production, work with existing CI/CD pipelines, monitor logs, and handle incidents within your assigned scope.

AI-FirstDevelopment: have used an AI coding agent or AI IDE (Claude Code, Cursor, GitHub Copilot, or equivalent) to write and modify real code.Able to write clear prompts and review AI-generated code.
