\section*{Appendix 2 --- Repository map and commands}
\addcontentsline{toc}{section}{Appendix 2 --- Repository map and commands}

The counts of Chapter 6 were produced from the repository root with the commands below. The workspace uses pnpm and Nx.

{\small
\begin{longtable}{|>{\raggedright\arraybackslash}p{\dimexpr 0.378\textwidth-2\tabcolsep-\arrayrulewidth\relax}|>{\raggedright\arraybackslash}p{\dimexpr 0.617\textwidth-2\tabcolsep-\arrayrulewidth\relax}|}

\textbf{Purpose} & \textbf{Command} \\ \hline
\endfirsthead
\hline
\textbf{Purpose} & \textbf{Command} \\ \hline
\endhead
Install & \texttt{pnpm install --frozen-lockfile} \\ \hline
Run explorer and API & \texttt{pnpm start} (explorer on port 4200, API on port 3000) \\ \hline
Run staff application & \texttt{pnpm exec nx run @datn/staff:serve} (port 4300, base path \texttt{/staff/}) \\ \hline
Local services & \texttt{docker compose -f infra/local/dev-stack.yml up -d} (Redis, PostgreSQL, mail catcher, S3-compatible store) \\ \hline
Run all tests & \texttt{pnpm exec nx run-many -t test} \\ \hline
Whole gate (lint, typecheck, build, test) & \texttt{pnpm check} \\ \hline
Rebuild occupation data & \texttt{pnpm data:build} \\ \hline
Try the AI layer without database & \texttt{pnpm exec nx run @datn/api:ai-lab -- --mode=fake --play=all} \\ \hline
Play a level-one scenario through HTTP & \texttt{node tools/dev/play-e2e.mjs} \\ \hline
\end{longtable}
